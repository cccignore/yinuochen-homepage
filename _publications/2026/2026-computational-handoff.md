abstract: >-
  A pre-rollout test checks whether resetting a robot policy's observation buffer
  reproduces a fresh process across task boundaries. In a controlled RoboFactory
  case study, explicit buffer resets match fresh-process action outputs, while
  retained history changes them; the test assesses reset conformance rather than
  downstream task success.
